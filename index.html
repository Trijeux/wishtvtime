⚙️ Paramètres

Comment ça marche : tes fiches sont sauvegardées dans un dépôt GitHub privé. Mets les mêmes infos ci-dessous sur ton PC et ton téléphone → les deux restent synchronisés.
  1. Crée un dépôt privé sur GitHub (ex : wishtvtime-data)
  2. Crée un jeton : GitHub → Settings → Developer settings → Personal access tokens (classic) → coche la case repo
  3. Colle le tout ci-dessous, puis Tester la connexion
🔒 Le jeton reste uniquement sur cet appareil (jamais envoyé ailleurs que GitHub). Garde ton dépôt privé.
Sauvegarde locale : tes fiches restent sur cet appareil. Choisis un fichier — l'app y enregistre automatiquement à chaque modification.
💡 Astuce : place ce fichier dans un dossier Google Drive / OneDrive et il se synchronisera entre tes appareils via ce service.
