⚙️ Paramètres

Comment ça marche : tes fiches sont sauvegardées dans un dépôt GitHub privé. Mets les mêmes infos ci-dessous sur ton PC et ton téléphone → les deux restent synchronisés.
  1. Crée un dépôt privé sur GitHub (ex : wishtvtime-data)
  2. Crée un jeton : GitHub → Settings → Developer settings → Personal access tokens (classic) → coche la case repo
  3. Colle le tout ci-dessous, puis Tester la connexion
🔒 Le jeton reste uniquement sur cet appareil (jamais envoyé ailleurs que GitHub). Garde ton dépôt privé.
Sauvegarde locale : tes fiches restent sur cet appareil. Choisis un fichier — l'app y enregistre automatiquement à chaque modification.
💡 Astuce : place ce fichier dans un dossier Google Drive / OneDrive et il se synchronisera entre tes appareils via ce service.
Aucun fichier choisi
Gratuit : crée un compte sur themoviedb.org, puis Paramètres → API → copie la clé API (v3 auth). 🔒 Stockée uniquement sur cet appareil.
Colle l'URL de ton proxy (Cloudflare Worker gratuit). Il interroge IGDB (la base de Playnite) si tu l'as configuré, sinon Steam. 👉 Crée-le en 5 min en suivant le fichier wishtvtime-proxy.worker.js. 🔒 Stocké uniquement sur cet appareil.
Tes clés sont chiffrées avec ta phrase puis synchronisées. Sur un autre appareil : configure la synchro, puis entre la même phrase et « Déverrouiller ». 🔒 La phrase n'est jamais sauvegardée — si tu l'oublies, les clés sont irrécupérables (re-saisis-les simplement).
Quand c'est activé, le statut (À faire / En cours / En pause / Terminé) est calculé tout seul d'après ta progression. Tu peux toujours Abandonner une fiche à la main. Le type Autre reste manuel. 🔄 Réglage synchronisé entre tes appareils.
